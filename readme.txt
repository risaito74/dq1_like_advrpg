# ワイが勇者になれるわけないじゃん、ムリムリ！（※ムリだった）

- 著者名：再豆リ仟
- ジャンル：Ren'Py製ノンフィールド型シンプル短編DQ1風RPG
- 実行ファイル：dq1_like_advrpg.exe
- URL：https://github.com/risaito74/dq1_like_advrpg

## 概要

陰キャ主人公「ワイ」が現代日本で何かと戦うメンタルRPG。
ギャル、ぴえん、メスガキの精神攻撃を耐え抜き人生経験を積んでレベルアップ！

## 操作方法

- 左クリック：メッセージを進める、選択肢の選択
- 右クリック：メニュー表示

## プレイ時間

約15〜30分
